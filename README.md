# Élite Centro Deportivo — rediseño web

Rediseño de [entrenaconelite.com](https://entrenaconelite.com/): sitio estático (HTML + CSS + JS, sin dependencias ni build).

## Estructura
- `index.html` — portada (hero, servicios, método, centro, contacto)
- `assets/css/styles.css` — estilos y diseño responsive
- `assets/js/main.js` — menú móvil, header al hacer scroll, animaciones

## Ver en local
Abrí `index.html` en el navegador, o serví la carpeta:

```bash
python3 -m http.server 8000
```

Identidad tomada del sitio actual: rosa `#e6005c`, verde `#00a98f`, fondo `#121212`, títulos en Kanit Black Italic y texto en Montserrat.

Las fotos y el logo de `assets/img/` están recortados de capturas de pantalla, así que tienen baja resolución. Antes de publicar conviene reemplazarlos por los originales en alta calidad, con los mismos nombres de archivo.
